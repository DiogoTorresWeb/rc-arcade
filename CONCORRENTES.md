# Concorrentes e referências — levantamento (23/09/2026)

Item do `TASKS.md` ("levantar 2-3 concorrentes/referências do nicho"). Pesquisa via
WebSearch/WebFetch, sites reais acessados ao vivo — não é achismo de memória de
treinamento.

## 1. RaceTech Systems (racetechsystems.com) — concorrente mais direto

Mesmo produto conceitual: **carro RC real + câmera FPV ao vivo + pista modular**,
vendido pra venues de entretenimento/arcade. É a comparação mais próxima que existe.

- **Público:** 100% B2B operador — nenhuma seção fala com o consumidor final.
- **Estrutura:** hero com proposta de valor → valor central (customização modular) →
  benefícios operacionais (engajamento, visitas repetidas) → recursos técnicos (FPV
  ao vivo, simulador, 4-10 jogadores) → três pilares (First Person View / Modular
  Track / Customização) → CTA único ("Enquire Now").
- **O que falta na página deles (oportunidade pro RC Arcade):** sem telemetria
  visível, sem prova em vídeo real rodando, sem números duros de capacidade, sem
  caso de sucesso. É promessa, não prova.
- **Leitura pro RC Arcade:** o bloco "La prueba" (vídeo real com telemetria na tela,
  cronômetro 00:42.381) é exatamente o que falta na Racetech — é a diferenciação
  mais forte que já temos e que o concorrente direto não tem.

## 2. AXSIM (axsim.racing) — fabricante de simulador full-motion pra venues

Produto diferente (simulador estático, não carro RC físico), mas **modelo de
audiência idêntico ao problema que o RC Arcade ainda não resolveu**: fala com
operador de venue E com comprador privado, na mesma página, com caminhos separados.

- **Hero:** "Extraordinary experiences start here" — posiciona como criador de
  experiência, não como fabricante de equipamento.
- **Estrutura:** logo após o hero, a página se bifurca em duas subseções dedicadas —
  uma pra "venues" (retenção, tempo de permanência, repetição), outra pra "uso
  privado" (peça de destaque, prazer de longo prazo). Prova social: parceria com
  F1® Arcade citada com números.
- **Leitura pro RC Arcade:** é a referência mais direta de como resolver a pergunta
  ainda aberta em `ESTRUTURA-DO-SITE.md` (bloco 6 "Las tres vías" + bloco 7
  "Público") — não precisa misturar B2B e B2C na mesma narrativa; separa em
  subseções com CTA e argumento próprios, sem competir pela atenção.

## 3. F1® Arcade (f1arcade.com) — não é concorrente direto, é referência de tom

Bar/experiência de simulador de F1, 100% B2C (reserva de mesa, evento, aniversário).
Não vende pra operador — é o operador. Útil só como referência de energia/tom, não
de estrutura comercial.

- **Estrutura:** reserva de evento privado (corporativo, aniversário) → experiência
  Grand Prix (telão, DJ, sim racing livre) → pacotes família (simulador full-motion,
  preço a partir de $39) → aluguel de espaço/venue.
- **Leitura pro RC Arcade:** confirma que a linguagem "energia de corrida real" funciona
  bem pro público final, mas não ajuda a resolver a decisão B2B — é tom, não
  estrutura. Não usar como referência de argumento comercial, só de atmosfera.

## Conclusão prática

- Nenhum concorrente direto (Racetech) tem prova em vídeo real com telemetria —
  isso reforça que o bloco "La prueba" do `ESTRUTURA-DO-SITE.md` é a maior vantagem
  competitiva disponível hoje, não só um bloco de conteúdo qualquer.
- AXSIM mostra um padrão testado pra separar B2B/B2C sem diluir a mensagem — vale
  usar como modelo de layout pro bloco 6+7, quando a decisão de priorização (ainda
  travada, ver `TASKS.md`) for tomada.
- Não achamos concorrente que combine os três (RC físico + FPV + telemetria +
  prova em vídeo) — não é motivo pra convicção de mercado (não validamos demanda
  aqui, só estrutura de site), mas é dado real pra registrar.
